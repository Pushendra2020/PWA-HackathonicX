# Smart Ticketing PWA
  This is a Demo version of Smart Ticketing PWA in this we show :-
  1. The service worker (For offline support)
  2. Lazy Loading for for fast loading speed even is slow internet

# How to Use this Demo
  1. Clone this repo.
  2. Simply run command # npm install
  3. npm run dev (For run the web application)
